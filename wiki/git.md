# Git 운용 규칙

이 저장소에서 **커밋·브랜치·PR·이슈·릴리스를 어떻게 다루는가.** 무엇을 만드는가는 [`policy/`](policy/index.md)·[`rules/`](rules/index.md)에 있고, 여기는 그것을 굴리는 방식이다.

각 규칙의 *이유*는 결정 기록에 있다 — 커밋 [`ADR-0016`](decisions/ADR-0016-commit-convention.md).

---

## 1. 커밋

### 형식

```text
<이모지> <타입>(<범위>): <제목>

<본문 — 무엇이 아니라 왜>

<트레일러>
```

예:

```text
🐛 fix(notes): 복원 경쟁 상황에서 최신 undo 유지

같은 노트를 연속으로 지우면 앞선 undo 타이머가 뒤 것을 덮어써
복원 대상이 어긋났다. 캡처한 노트 신원을 undo가 함께 들고 다니게 했다.

Refs #12
```

### 이모지 ↔ 타입 (1:1 고정)

이모지는 **타입에서 기계적으로 결정된다.** 고를 여지가 없다 — 고를 수 있으면 어긋난다.

| 이모지 | 타입 | 쓰는 때 |
|---|---|---|
| ✨ | `feat` | 사용자가 할 수 있는 일이 늘어남 |
| 🐛 | `fix` | 의도한 동작과 실제가 달랐던 것을 고침 |
| 📝 | `docs` | 문서·위키만 바뀜 (`wiki/`, `README.md`, `docs/`) |
| ♻️ | `refactor` | 동작은 그대로, 구조만 바뀜 |
| ✅ | `test` | 테스트만 더하거나 고침 |
| ⚡️ | `perf` | 측정 가능한 성능 개선 |
| 🔧 | `chore` | 빌드·의존성·설정·버전 bump 등 그 외 |
| 👷 | `ci` | `.github/workflows/**` |

이 표에 없는 타입·이모지는 쓰지 않는다. 표를 늘려야 하면 표를 먼저 고친다.

### 범위(scope)

선택이지만 웬만하면 적는다. 앱 모듈 이름 또는 운영 영역을 쓴다.

`notes` · `editor` · `bible` · `parser` · `db` · `share` · `settings` · `theme` · `list` · `workspace` · `search` · `ota` · `eas` · `release` · `deps` · `wiki`

두 영역에 걸치면 범위를 비우거나(`✨ feat: …`) 커밋을 나눈다. 범위 두 개를 쉼표로 잇지 않는다.

### 제목

- **한국어**로 쓴다. 타입·범위·트레일러는 영어 그대로다.
- **명사형으로 끝낸다** — "추가", "수정", "분리". "추가했다"·"추가함"은 쓰지 않는다.
- 마침표를 찍지 않는다. 50자 안쪽을 목표로 한다.
- 무엇을 바꿨는지 한 줄로 읽히게 쓴다. 이유는 본문에 쓴다.

### 본문

한 줄로 자명한 변경이면 생략한다. 그렇지 않으면 **왜 이 변경이 필요했는지**를 적는다. diff를 한국어로 옮긴 본문은 쓰지 않는다 — diff가 이미 그것을 말한다.

### 파괴적 변경

데이터 스키마, 공유 마크다운 포맷, 설정 파일 형식처럼 **이미 나간 앱의 데이터를 못 읽게 만드는 변경**은 반드시 표시한다.

```text
✨ feat(db)!: notes 스키마에서 body_text 컬럼 제거

BREAKING CHANGE: 1.0.x가 만든 DB는 이 버전에서 열리지 않는다. 마이그레이션은 …
```

타입 뒤 `!`와 `BREAKING CHANGE:` 푸터를 **둘 다** 쓴다. 하나만 쓰면 도구와 사람 중 한쪽이 놓친다.

### 트레일러

| 트레일러 | 쓰는 때 |
|---|---|
| `Refs #12` | 관련은 있지만 이 커밋으로 끝나지 않는 이슈 |
| `Closes #12` | 이 변경이 머지되면 닫히는 이슈 |
| `Co-Authored-By: … <…>` | 에이전트·공동 작업자 |
| `BREAKING CHANGE: …` | 위 참조 |

**`[skip ci]`는 쓰지 않는다.** 문서만 고친 커밋도 예외가 아니다. `main`의 OTA 발행이 CI 성공(`workflow_run`)에 매달려 있어, CI를 건너뛰면 **배포가 조용히 나가지 않는다**([`POL-RELEASE-001`](policy/POL-RELEASE.md)).

### 커밋을 나누는 단위

되돌릴 수 있는 가장 작은 단위 하나. 리팩터링과 기능 추가를 한 커밋에 담지 않는다 — 되돌릴 때 둘 중 하나만 되돌릴 수 없다. 동작을 바꿨으면 **관련 `RULE`/`CONTRACT` 수정을 같은 커밋에** 넣는다([`workflow.md`](workflow.md) 5단계).
