# ADR-0015 · 외장 키보드 단축키를 범위에서 제외한다

```yaml
id: ADR-0015
status: accepted
supersedes: DESIGN.md "키보드 단축키 (1급 시민)"
statement: ⌘/Ctrl 조합 단축키를 구현하지 않는다. 키보드 상호작용은 필드 간 Return 이동과 인용 확정 공백까지로 한정한다.
confidence: 기록됨
source:
  - docs/plans/2026-05-17-ch-life-v1-spec.md 1.5, 6.3, 9장
```

## 맥락

`DESIGN.md`는 외장 키보드 시나리오(아이패드 매직키보드, 갤탭 키보드 케이스)를 **1급 시민**으로 두고 단축키 5개 이상을 성공 기준에 넣었다(⌘N/⌘S/⌘B/⌘K/⌘F, Tab/Esc). v1 spec 시점에 **명시적으로 범위에서 뺐다.**

## 결정

단축키를 만들지 않는다. Expo 환경에서 키 이벤트를 다루는 추가 라이브러리를 도입하지 않는다.

## 귀결

- 확정 키가 Tab일 수 없게 되어 [`ADR-0002`](ADR-0002-space-trigger.md)의 space 트리거로 이어졌다. **이 결정이 없었다면 자동완성 UX 전체가 달랐다.**
- 태블릿 + 외장 키보드 사용자는 손을 화면으로 옮겨야 한다. 원래 세운 차별점 하나를 접은 셈이다.
- 대신 메타 헤더의 **Return 연쇄 이동**([`RULE-EDIT-011`](../rules/editor-insert.md))이 키보드만으로 헤더를 통과하는 최소한의 경로로 남았다.
- 재도입한다면 `Esc` 취소가 없는 space 트리거의 비가역성부터 다시 봐야 한다.
