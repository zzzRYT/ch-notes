# 씀씀 기능 확장과 사업 기회 리서치

조사일: 2026-10-08. 현재 워크트리의 구현과 경쟁사의 공식 웹사이트·공식 스토어 등록 정보를 기준으로 작성했다. 성장과 개인 유료화, 교회 대상 판매를 함께 검토한다. 실제 사용자 인터뷰·GA4 수치·결제 전환 데이터는 확인하지 않았다. 이 문서는 기능 후보를 고르기 위한 조사이며, 현재 정책이나 확정 로드맵을 변경하지 않는다.

## 추천 방향

**씀씀의 확장 방향으로 “주일에 적은 말씀을 평일에도 활용하는 개인 기록 도구”를 추천한다.** 가장 먼저 검증할 기능은 주간 설교 복습이다. 그다음 성경 구절과 과거 노트 연결, 정리·출력 유료 기능을 검토한다. 교회 대상 사업은 설교 자료와 소그룹 질문 배포를 작은 수동 파일럿으로 시작한다.

이 순서는 조사에 따른 판단이다. 무료 경쟁 기능은 풍부하고, 씀씀의 현재 자산은 사용자 자신의 설교 기록이다. 개인화된 기록을 재활용하면 새로운 콘텐츠를 매일 제작하지 않고도 반복 사용 이유를 만들 수 있다는 가설이다. 효과나 지불 의사는 아직 검증되지 않았다.

전체 백업·복원은 별도의 선행 과제다. 안전하게 기록을 쌓을 수 있어야 장기 사용과 유료 가치도 생긴다. 기본 백업을 결제 장벽으로 만들기보다는 신뢰를 확보하는 기능으로 권한다.

- Spirit Notes의 2024년 리뷰에는 노트 소실·기기 간 전달·백업 불만이 있고, 같은 리뷰의 수정본에는 문제가 해결됐다고 적혀 있다. **현재 결함이라는 주장으로 사용하지 않는다.** 기록 도구에서 신뢰가 중요하다는 문제 단서로만 사용한다. [리뷰와 수정본](https://apps.apple.com/us/app/spirit-notes-sermon-bible/id1531045060)

두 사례 모두 해외의 소수 리뷰다. 한국 씀씀 이용자에게 같은 문제의 빈도나 중요도가 있다고 단정할 수 없다.

### A. 주간 설교 복습: 성장 측면에서 먼저 검증

대상은 설교를 매주 적지만 주중에는 앱을 열 이유가 적은 이용자다. 실제 빈도는 인터뷰로 확인해야 한다.

예시 흐름: 주일에 노트 작성 → 평일에 “지난 설교 돌아보기”로 같은 노트 열기 → 적용할 일 한 가지 작성 → 다음 주에 실행 여부와 느낌 기록. 초기에는 직접 고르는 최근 노트와 고정 질문을 사용한다. 알림을 추가한다면 사용자가 선택한 시간의 로컬 알림으로 제한한다. 스트릭·점수·자동 신앙 평가·매일 새 콘텐츠는 필요 없다.

차별화 가설은 “일반적인 오늘의 묵상”보다 자신이 실제 들은 말씀을 다시 쓰는 데 있다. 노트 작성량보다 **주일에 작성한 사람이 주중에 기존 기록을 열고 적용을 남기는 비율**을 본다. 일반 기도·묵상 무료 공급의 근거: [YouVersion](https://www.youversion.com/bible-app), [Church Notes](https://www.churchnotesapp.com/pricing).

### B. 말씀과 내 기록 연결: 기존 데이터의 가치 증가

예시: 요한복음 15장을 읽다가 “이 구절이 들어간 내 노트”를 열어 지난 설교를 확인한다. 현재 태블릿의 “인용” 탭은 현재 노트의 인용 목록이며, 앱 전체의 관련 노트를 찾는 역방향 연결과는 다르다. 근거: [BiblePanel](../../apps/ch-life/src/pages/notes/ui/BiblePanel.tsx).

최초 범위는 명시적으로 인용한 구절과 관련 노트 목록이다. 의미 검색·AI 해석·관주 서비스를 붙이지 않는다. `citedRefs`는 시작점이지만 문자열 검색만으로 `요 15:1-5`와 `요 15:3`의 겹침을 정확히 처리할 수 있다고 가정하지 않는다. 대표 본문 `scripture`를 포함할지는 별도 범위 결정이 필요하다.

경쟁사도 구절에서 노트를 여는 기능을 제공하므로 독점적 기능은 아니다. 씀씀에서는 한국어·큰 글씨·쉬운 접근과 함께 검증해야 한다. [Spirit Notes 공식 기능](https://www.spiritnotes.com/).

### C. 보관함·PDF: 개인 결제의 작은 실험

예시: “올해 우리 교회 설교 노트” 또는 “이번 수련회 기록”을 기간·설교자로 모아 목차 있는 PDF로 만든다. 구매 가치는 기록을 보기 좋게 보관·인쇄하는 편의에 둔다. 기본 작성·접근성·사용자 원본 파일 반출은 유지하는 방안을 권한다.

처음에는 기존 노트로 만든 PDF 견본을 보여주고 실제 출력·보관에 쓰는지 확인한다. 가격 후보로 **정리·출력 묶음 1회 구매 9,900원과 19,900원**을 따로 제시할 수 있다. 이는 경쟁사에서 검증한 가격이 아니라 인터뷰용 가설이다. 비용이 반복되지 않는 로컬 편의를 곧바로 월 구독으로 묶을 이유는 아직 약하다.

관련 노트는 사용자가 직접 고른다. 공개 공유 카드에 이름·교회·기도 내용이 자동 포함되게 하지 않는다. 초기에 인쇄 배송·템플릿 마켓·출판 사업까지 범위를 늘리지 않는다.

### D. 교회 자료 배포: 성장 채널과 기관 매출을 같이 시험

개인 이용자는 설교 본문과 질문을 받는다. 구매자는 매주 자료를 만들고 배포하는 교역자·소그룹 운영자다. 이 둘의 가치를 구분해야 한다.

수동 파일럿은 2개 교회 또는 소그룹에서 4주간 진행하는 안이다. 담당자가 제목·설교자·날짜·본문·질문 3개를 넣은 파일을 배포하고, 참가자는 씀씀에서 가져와 개인 기록을 덧붙인다. 현재 한 파일 가져오기 경로로 시작할 수 있지만, 앱이 없는 사람이 설치하고 가져오기까지 완료하는 과정은 직접 검증해야 한다. 최초에는 개인 노트가 운영자에게 전송되지 않는 흐름으로 한정한다.

YouVersion은 이미 무료 설교 자료·Events·QR 배포를 제공한다. 따라서 “주보 링크를 만든다”만으로 유료화를 권하지 않는다. **한국어 자료 제작·개인 기록 연결·주중 나눔 준비의 시간을 실제로 줄였을 때** 운영 편의를 판매할 가설이 생긴다. [YouVersion 교회 서비스](https://www.youversion.com/churches), [Events 활용](https://www.youversion.com/churches-onboarding-blogs/203-events-digital-engagement-during-service).

가격 인터뷰용 후보는 교회 월 19,000원과 39,000원이다. 아직 국내 시장 가격 근거가 없다. 수동 파일럿의 만족도만으로 확정하지 말고 예산권자의 구체적인 구매 의사·유료 파일럿 참여를 확인한다. 이후 관리자 화면·팀 권한·콘텐츠 서버가 필요한지 판단한다. 기관용 배포 유료 사례: [PrayerMate Platform](https://www.prayermate.net/platform?currency=GBP).

## 5. 먼저 할 사용자 검증

아래는 실행 제안이다. 사용자에게 연락하거나 앱 기능을 구현하지 않았다. 숫자는 통계적 기준이 아닌 작은 파일럿의 사전 판단 기준이다.

### 인터뷰: 말보다 기존 행동 확인

최근 한 달에 설교 노트를 2회 이상 쓴 사람 6명, 종이·일반 메모 앱 이용자 4명, 교회 자료 담당자 3명 정도를 모집하는 안이다. 연령과 기기를 섞고, 모집 조건에 맞는 사람이 없다면 활성 이용자 확보를 먼저 과제로 둔다.

- 지난 설교 노트를 마지막으로 다시 본 상황과 찾는 데 걸린 과정은 무엇인가?
- 설교 이후 적용·기도·소그룹 나눔을 지금 어디에 기록하는가?
- 실제로 노트를 잃었거나 기기 교체·폰과 태블릿 전환에 어려움을 겪었는가?
- 성경 앱과 기록 앱을 함께 쓸 때 어떤 작업을 반복하는가?
- 유료 앱을 써봤다면 무엇에 돈을 냈고, 무엇 때문에 중단했는가?
- 자료 담당자는 주당 제작·수정·배포에 얼마나 쓰며, 실제 예산을 누가 승인하는가?

“이 기능이 있으면 쓰겠나”만 묻지 않는다. 가능하면 민감한 본문을 가린 상태에서 실제 흐름을 관찰한다. 종교·기도·교인 정보가 들어간 원본을 인터뷰 자료로 무조건 수집하지 않는다.

### 4주 파일럿의 판단 기준

| 실험 | 확인할 행동 | 다음 단계의 임시 기준 | 중단·수정 신호 |
|---|---|---|---|
| 주간 복습, 10명 | 새 노트 작성 후 주중에 기존 노트를 열고 적용 기록 작성 | 6명 이상이 서로 다른 2주에 반복 | 안내를 받은 첫 주만 사용. 내용을 다시 볼 이유가 없다는 반응 |
| 구절·과거 노트 연결, 8명 | 자기 기록에서 실제로 찾고 싶던 노트를 찾기 | 5명 이상이 서로 다른 날짜에 2회 이용 | 관련 기록량 부족, 원하는 검색은 구절보다 설교자·본문 키워드라는 반응 |
| PDF 견본, 10명 | 자기 기록의 출력본을 실제 저장·인쇄·공유 | 3명 이상이 실제 사용하고 구체적인 구매 의사 표시 | 보기 좋다는 반응만 있고 사용할 상황·가격 수용 없음 |
| 교회 자료 배포, 2곳 | 담당자 4주 반복 배포, 참가자 다음 주 재사용 | 1곳 이상이 반복 운영하고 예산권자가 유료 파일럿 의사 표시 | 기존 무료 도구·카카오톡보다 일이 늘거나 참가자가 가져오기를 못함 |

표본이 작으므로 기능 효과를 인과적으로 입증하거나 전체 사용자 전환율로 외삽하지 않는다. 먼저 기존 재방문·기록 재열람 행동을 확인하고 비교한다. PDF는 계절성이 있을 수 있어 4주 미사용만으로 연말·수련회 수요까지 없다고 판단하지 않는다.

현재 Firebase는 자동 이벤트만 수집하므로 노트 작성·재열람·복습 전환을 그대로 볼 수 없다. 초기 파일럿은 참가자의 동의하에 확인한 사용 행동·내용 없는 집계로 평가할 수 있다. 상시 기능 이벤트를 넣는다면 먼저 이벤트 범위와 정책·신고의 일치를 검토한다. 제목·본문·성경 참조·교회명을 이벤트 속성으로 전송하는 제안은 하지 않는다. 근거: [Analytics 결정](../../wiki/decisions/ADR-0029-firebase-analytics.md), [개인정보 정책](../../wiki/policy/POL-PRIVACY.md).

## 6. 사업 목표별 선택

| 가장 중요한 목표 | 첫 기능·실험 | 그 뒤에 볼 것 |
|---|---|---|
| 재사용률·사용자 성장 | 주간 설교 복습 | 성경과 기록 연결, 교회 배포 경유 유입 |
| 개인 사용자 유료화 | 보관함·PDF 견본과 가격 테스트 | 반복 사용이 확인된 고급 정리 기능. 다기기 수요가 확인되면 동기화 |
| 교회·소그룹 대상 판매 | 수동 설교 자료·질문 배포 파일럿 | 실제 제작 시간 절감과 예산권자 확인 후 관리자 도구 |

공통 선행 검토는 전체 백업·복원이다. 그다음 한 목표의 한 실험부터 선택한다. 기능 수보다 반복 사용·기록의 축적 가치·구매자의 실제 업무를 기준으로 투자한다.

## 조사 범위와 남은 불확실성

경쟁 제품 8개의 공개 기능·가격, 사용자 리뷰 일부, 씀씀의 현재 저장·검색·공유·성경 화면과 정책을 확인했다. 새 기능 구현, 정책 변경, 사용자 연락, 결제, 배포는 수행하지 않았다.

미확인 항목은 씀씀의 실제 활성 사용자와 유지율, 한국 사용자 지불 의사, 경쟁사의 실제 결제 화면·매출, 교회 영업 경로·구매 주기, 콘텐츠 계약 비용, 클라우드 운영 원가다. 따라서 이 문서의 가격·우선순위는 검증할 가설이며 출시 결정이나 매출 예측으로 취급하지 않는다.
