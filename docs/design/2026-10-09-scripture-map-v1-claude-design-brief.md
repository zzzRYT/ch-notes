# 씀씀 말씀 지도 V1 — Claude Design 브리프

이 파일 전체를 Claude Design에 전달하면 된다.
다른 문서나 이전 대화 없이 화면을 설계할 수 있도록 작성했다.
아래 요구사항으로 한국어 모바일 앱의 시안을 제작하고, 가능하면 화면 간 클릭 흐름까지 연결해 달라.
앱의 기존 코드 구현·외부 서비스 연결·출시는 요청하지 않는다.

## 1. Product and Intent

앱 이름은 **씀씀**이며 교회 설교 노트를 기기에 기록하는 앱이다.
말씀 지도는 사용자가 기록한 성경 본문의 배경과 사건 시대를 연결해, 자신의 노트를 다른 맥락으로 다시 읽도록 돕는 기능이다.

사용자가 느낄 핵심은 ‘내가 남긴 말씀과 생각이 쌓이고 있다’이다.
기록 개수로 신앙을 평가하거나 성경 지역을 모두 정복하도록 유도하지 않는다.
기존의 차분하고 모던한 노트 앱 안에서 자연스럽게 이어지는 화면으로 디자인한다.

설교 노트는 개인적인 글이다.
지도, 연결 결과, 기록 목록은 모두 오프라인으로 작동하는 제품을 전제로 한다.
화면에 로그인, 서버 분석, 광고, 결제, 현재 위치 권한을 추가하지 않는다.

## 2. The First Version

저장된 설교 본문과 인용 구절을 미리 검토한 사건 배경에 연결한다.
자유롭게 적은 글 전체를 AI가 분석하거나 모든 성경 구절의 배경을 아는 기능으로 표현하지 않는다.
검토한 일부 본문부터 연결되므로 기록이 있어도 표식이 없을 수 있다.

첫 지도 범위는 갈릴리·예루살렘·여리고 주변이다.
지도는 별도 화면이며 기존 노트 목록이 주 진입 화면이다.
쓰기 화면에 지도를 상시 배치하지 않는다.

필수 기능은 지도와 동일한 지역·장소 목록, 사건 시대 필터, 지역 상세, 시대별 장소 상세, 관련 노트 열기다.
마커 애니메이션이나 미묘한 화면 전환은 가능하지만 정보 전달보다 앞서지 않게 한다.

## 3. Time and Place Rules

**시대는 성경 사건이 벌어진 시대다.**
설교를 들은 날짜·노트 작성일·성경 책의 저작 시기와 다르다.
신약 책이 구약 사건을 회상할 수 있으므로 ‘구약/신약 책’만으로 장소를 나누지 않는다.

세 가지 상황을 모두 표현한다.

| 상황 | 지도와 상세의 표현 |
|---|---|
| 같은 지역에서 도시의 위치가 달라짐 | 시대별 장소를 다른 위치로 유지 |
| 같은 위치에 시대별 다른 건물·장소가 존재 | 좌표는 유지하고 시대별 장소 항목을 나눔 |
| 같은 장소가 시대에 따라 다른 이름으로 불림 | 해당 시대의 이름과 당시 맥락을 표시 |

초기 시대 선택은 **전체 / 여호수아 시대 / 왕국 시대 / 예수님 사역 시대**다.
가로로 스크롤 가능한 한 줄 필터이며 선택 여부는 배경·윤곽·텍스트로도 구분한다.
데이터의 시대가 불명확할 때만 ‘시대 미상’을 추가한다.

정확한 기원전·후 연도 슬라이더를 만들지 않는다.
검증되지 않은 연도를 자동으로 부여하지 않는다.
시대별 국가 경계·왕국 영토·옛 해안선도 그리지 않는다.

지역은 탐색을 위한 묶음이다.
‘여리고 지역’ 안에 ‘여리고 · 여호수아 시대’와 ‘여리고 · 예수님 사역 시대’가 따로 있을 수 있다.
이 지역 묶음의 기록 수는 두 장소의 기록 수를 단순히 더한 값이 아니다.

## 4. Visual Identity

**방향:** 큰 제목, 충분한 여백, 얇은 구분선, 한 가지 강조색, 읽기 좋은 한국어 타이포그래피.
지도는 기록을 탐색하는 도구다.
관광 안내 앱이나 게임 월드맵처럼 보이지 않게 한다.

현재 앱에서 쓰는 스타일을 이어간다.

- 기본 화면 여백: 약 20–22px.
- 제목 크기: 30px, 굵게. 섹션 제목 20px, 노트 제목 17px, 본문 15px, 보조 문구 13px, 짧은 캡션 11px.
- 기본 글꼴: Pretendard를 사용할 수 있으면 사용하고, 없으면 한글을 지원하는 시스템 산세리프를 사용한다.
- 모서리: 작은 컨트롤은 8–10px, 지도 프레임과 상세 패널은 최대 16px.
- 주요 버튼·목록 선택 영역은 최소 44px. 작은 지도 표식도 별도 목록으로 선택할 수 있어야 한다.
- 기존 아이콘의 방향은 가는 선의 Lucide 계열이다.
- 대비가 부족한 작은 글자는 불투명한 본문 색으로 조정한다. 축소한 글자로 레이아웃을 맞추지 않는다.

| 토큰 | Focus 기본 시안 | Dark 시안 |
|---|---|---|
| bg | #FFFFFF | #0E0D0C |
| paper | #FFFFFF | #1A1916 |
| ink | #15140E | #F5F3EE |
| ink2 | rgba(21,20,14,0.55) | rgba(245,243,238,0.66) |
| rule | rgba(21,20,14,0.06) | rgba(245,243,238,0.10) |
| accent | #6B7280 | #F5B35E |
| accentSoft | rgba(107,114,128,0.08) | rgba(245,179,94,0.14) |

시대를 여러 색상으로 칠하지 않는다.
색상 외에 이름·선택 윤곽·표식 모양을 사용한다.
추가 테마에는 기존 minimal의 파랑과 paper의 갈색 강조색이 적용될 수 있어야 한다.

무화과나무, 캐릭터, 이모지 장식, 열매, 보석, 경험치, 레벨, 배지, 연속 기록, 반짝이는 보상 연출은 사용하지 않는다.
지도에 장식적인 성경 구절이나 큰 배경 일러스트를 넣지 않는다.

## 5. Map Presentation

지중해가 서쪽, 갈릴리 호수가 북쪽, 사해가 남쪽에 있는 배경 구도를 유지한다.
기본 지형은 저채도 면과 가는 윤곽으로 표현하고, 지명과 기록 표식이 주목받게 한다.
현재 국가 경계·도로·관광 시설·현재 위치 점은 표시하지 않는다.

지역 표식에는 지역 이름과 연결된 고유 기록 수를 제공한다.
여러 시대의 장소가 겹친 묶음은 ‘2시대’ 같은 짧은 정보로 구분할 수 있다.
미연결 지역을 흐리게 도배해 ‘아직 달성하지 못했다’는 인상을 주지 않는다.

서로 다른 좌표가 전체 지도에서 겹치면 하나의 **지역 묶음 표식**으로 표현한다.
묶음을 누르면 지역 상세에서 시대별 장소와 지역 확대 도식을 보여준다.
이 확대 도식은 기기에 포함된 지도이며 자유 이동·핀치 줌은 첫 버전에 없다.

같은 좌표에 여러 시대의 장소가 있으면 표식을 임의로 흩뜨리지 않는다.
지역 상세의 시대별 항목을 선택해 당시 장소와 연결 기록을 구분한다.
실제 위치와 선택 항목의 관계가 보이도록 표식 선택과 목록 선택을 동기화한다.

장소 설명에는 필요에 따라 ‘도시 주변의 대략적인 위치’, ‘성전 일대’처럼 정밀도를 전달한다.
전체 안내는 ‘지도의 위치는 본문 배경을 이해하기 위한 참고 정보예요.’를 사용한다.

자료가 제공되지 않은 좌표·건물 배치·고대 경계를 임의로 사실처럼 만들지 않는다.
디자인용 배치가 도식이면 프레임 주석에 ‘위치 도식 · 출시 좌표 검토 필요’를 명시한다.
지도 지형·표식·라벨은 나중에 실제 데이터로 교체할 수 있도록 분리한다.

## 6. Screen Deliverables

모바일 기준 390 × 844, 태블릿 기준 1194 × 834를 사용한다.
기능은 같고 레이아웃만 달라진다.
앱의 가로 너비 900px 이상에서는 지도와 목록을 나란히 배치할 수 있다.

### M0. Notes Entry

현재 노트 목록의 분위기를 유지한다.
상단 브랜드 ‘설교 노트’, 큰 제목 ‘노트’, 검색 영역, 날짜별 기록 목록, 새 노트 동작이 있다.
‘말씀 지도’ 진입은 제목·요약 아래의 작은 텍스트 행으로 제공한다.
기존 성경 읽기·검색·가져오기·설정 아이콘 옆에 다섯 번째 아이콘을 억지로 넣지 않는다.

태블릿은 노트 사이드바의 제목 아래에서 동일한 진입을 제공한다.
지도에 들어가기 전 저장 여부를 별도 확인 질문으로 묻는 화면은 만들지 않는다.

### M1. Map Overview

상단: 뒤로 ‘노트’, 화면 제목 ‘말씀 지도’, 지도 안내를 확인하는 작은 동작.
요약: ‘6편의 기록 · 3지역’.
설명: ‘기록한 말씀의 배경을 따라 돌아보세요.’
그 아래에 시대 필터와 지도를 배치한다.

지도 아래에는 지역 목록을 제공한다.

- 여리고 — 2시대 · 3편
- 예루살렘 — 2시대 · 2편
- 가버나움 — 예수님 사역 시대 · 1편

전체 기록 8편 중 지도에 연결되지 않은 2편이 있다.
필요하면 지도 아래의 작은 안내에서 이 사실을 알릴 수 있으나 경고·실패 표시로 표현하지 않는다.
‘일부 본문부터 지도에 연결돼요.’가 기본 설명이다.

### M2. Region with Multiple Historical Places

전체 지도에서 여리고 묶음을 선택한 상태다.
모바일에서는 아래 상세 영역으로, 태블릿에서는 우측 상세 영역으로 표현한다.
모바일 상세는 일반 스크롤 패널이며 드래그 제스처만으로 정보를 볼 수 있게 하지 않는다.

제목 ‘여리고’, 요약 ‘2시대의 장소 · 3편의 기록’.
전체 지도보다 넓게 보이는 지역 확대 도식을 제공한다.
서로 다른 위치의 두 시대 장소를 구분한다.

장소 목록:

- 여리고 · 여호수아 시대 — 노트 2편
- 여리고 · 예수님 사역 시대 — 노트 2편

두 항목에는 공통 노트가 있으므로 지역의 고유 기록 수는 3편이다.
각 장소의 시대·위치 설명·관련 본문을 확인한 뒤 노트 목록으로 들어간다.

### M3. Place and Related Notes

여리고 · 예수님 사역 시대를 선택한다.
장소 이름, 사건 시대, 대략적인 위치 설명, 연결 배경 ‘삭개오를 만난 이야기’, 관련 본문 ‘누가복음 19:1-10’을 보여준다.
이 사건 이름은 디자인용 예시이며 출시 설명문은 검토한 데이터를 따른다.

아래에는 관련 노트 2편을 기존 앱처럼 간결한 행으로 보여준다.
행에는 제목, 날짜, 연결된 본문을 제공한다.
한 노트의 인용이 여러 사건과 연결되면 이 장소와 연결된 인용만 요약한다.
행 선택은 기존 노트 에디터로 이동한다.
지도에서 연 에디터의 뒤로 문구는 ‘말씀 지도’로 표시한다.

목록을 닫으면 선택한 지역으로 돌아간다.
노트 에디터에서 돌아오면 이전 필터·지역·장소를 유지하며 저장한 내용을 반영한다.
지도에 복귀하기 전 저장이 끝나도록 하고, 저장 실패 시 에디터에서 기존 오류를 보여준다.
저장 확인을 위한 별도 승인 대화상자는 만들지 않는다.

### M4. One Location across Different Periods

예루살렘 성전 일대에 서로 다른 시대의 장소가 겹친 상태다.
지도 위 표식은 같은 위치를 유지한다.
상세에서 다음 항목을 따로 보여준다.

- 예루살렘 성전 · 왕국 시대 — 1편
- 예루살렘 성전 · 예수님 사역 시대 — 1편

두 항목은 개념 검증용이다.
개별 성전의 정확한 구조·면적·연대를 지도에 그리지 않는다.
선택한 시대의 장소 이름, 배경 설명, 본문, 노트 목록이 바뀌는 것이 화면의 핵심이다.

### M5. Period Filter

‘예수님 사역 시대’를 선택한다.
요약은 ‘4편의 기록 · 3지역’이며 해당 시대의 장소와 노트만 보인다.
기존 선택 장소가 새 시대에 속하지 않으면 장소 선택을 해제한다.

‘여호수아 시대’는 ‘2편의 기록 · 1지역’.
‘왕국 시대’는 ‘1편의 기록 · 1지역’.
각 시대 기록 수의 합은 전체 고유 기록 수와 같을 필요가 없다.

### M6. Empty and Unlinked States

노트가 없는 경우:

- 제목 ‘말씀의 배경을 기록으로 남겨보세요’
- 설명 ‘설교 본문이나 인용 구절을 기록하면, 연결할 수 있는 장소가 지도에 표시돼요.’
- 동작 ‘노트로 돌아가기’

노트는 있으나 연결된 장소가 없는 경우:

- 제목 ‘아직 지도에 연결된 기록이 없어요’
- 설명 ‘일부 본문부터 지도에 연결돼요. 작성한 노트는 그대로 남아 있어요.’
- 동작 ‘노트로 돌아가기’

시대 필터의 결과가 없는 경우:

- 제목 ‘이 시대에 연결된 기록이 없어요’
- 동작 ‘전체 시대 보기’

표식을 얻기 위해 미지원 본문을 다시 쓰도록 요구하지 않는다.
연결되지 않은 기록도 가치가 있다는 톤을 유지한다.

### M7. Loading, Error, and Information

초기 조회 중에는 지도 프레임·목록의 단순한 로딩 표현을 쓴다.
로딩 완료 전 ‘0편’으로 단정하지 않는다.
AI 분석·서버 연결 로딩처럼 보이지 않게 한다.

조회 오류는 ‘기록을 불러오지 못했어요.’와 ‘다시 시도’.
빈 결과와 오류를 구분한다.

안내에는 다음 내용을 읽기 쉬운 문장으로 제공한다.

- 저장한 설교 본문과 인용 구절을 바탕으로 연결한다.
- 시대는 성경 사건의 시대를 뜻한다.
- 장소와 시대가 확인된 일부 본문부터 제공한다.
- 같은 지역에도 시대별 다른 장소가 있다.
- 지도 위치는 참고용이며 정확한 사건 지점을 보증하지 않는다.
- ‘출처 및 라이선스’에서 데이터 이용 조건을 확인할 수 있다.

외부 웹페이지를 열어야만 안내를 읽을 수 있게 하지 않는다.

### T1. Tablet and D1. Dark

태블릿은 왼쪽 지도, 오른쪽 지역·장소·관련 노트 영역을 사용한다.
선택이 없을 때 오른쪽에는 지역 목록을 제공한다.
태블릿 전용 기능이나 다른 집계 규칙은 만들지 않는다.

Dark는 M1과 M2 또는 M4를 제작해 지도 윤곽·표식·본문 대비를 확인한다.
밝은 지도 이미지를 어두운 화면에 그대로 얹지 않는다.

## 8. Output Expectations

완성된 화면과 함께 다음을 제공해 달라.

- M0–M7, T1, D1에 해당하는 이름 붙인 프레임.
- 노트 목록 → 지도 → 지역 → 시대별 장소 → 노트 → 지도 복귀의 클릭 흐름.
- 전체 시대 → 특정 시대 → 전체 시대 복귀의 흐름.
- 지도 표식, 시대 필터, 지역 행, 장소 행, 노트 행, 빈 상태의 재사용 가능한 구성 요소.
- 기본·선택·겹침·빈 결과·로딩·오류 상태의 차이.
- 사용한 색상·타입·간격과 시대별 장소 구분 방식의 짧은 설명.
- 디자인 도식과 검증된 지리 데이터의 경계를 알려주는 프레임 주석.

핵심 평가 기준은 기록의 의미, 시대별 장소 구분, 기존 UI와의 연속성, 지도를 누르지 않아도 같은 기록을 찾는 접근성이다.
화면을 풍성하게 만들려고 요구사항 밖의 기능을 추가하지 않는다.
