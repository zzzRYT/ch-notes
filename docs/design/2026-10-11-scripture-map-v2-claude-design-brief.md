# 씀씀 말씀 지도 V2 (P1: 지중해·신약) — 시안 개정 브리프

Claude Design 프로젝트 「말씀 지도.html」(V1)을 **개정**하기 위한 요구 사항이다. V1 시안의 구성 요소·토큰·화면 흐름(M0–M7, T1, D1)은 그대로 쓰고, 아래 **추가·변경 분만** 그린다. 범위 정의의 근거는 `docs/plans/2026-10-11-1700-feat-scripture-map-v2-scope-plan.md`.

## 1. 바뀌는 전제

| V1 | V2 (P1) |
|---|---|
| 지도 범위: 갈릴리·예루살렘·여리고 주변 | **지중해 전역** (이탈리아 – 그리스 – 소아시아 – 구브로 – 시리아 – 북아프리카 해안). 경도 8–45, 위도 28–47을 기본으로 한다 |
| 지역 표식 = 지역 하나 | 지역이 수십 곳으로 늘어, **가까운 표식은 묶음 표식으로 합쳐 보이고 확대하면 풀린다** |
| 전체 지도 보기 범위 고정 | 시대 필터에 걸린 기록을 **감싸는 범위로 자동 맞춤** (최소: V1 성지 범위) |
| 시대 3개 | 시대 필터에 **초대교회**가 추가된다(예수님 사역 시대 뒤). 나머지는 그대로 |

## 2. 하지 않는 것 (시안에도 그리지 않는다)

- **권역 표식·권역 계층**(예: "그리스 5편" 같은 상위 표식). 디자인이 아직 없어 이번에 제외한다.
- **연도·연대 표기.** 어떤 화면에도 연도를 쓰지 않는다.
- **영토·왕국의 면**과 국경, 도로·항로 지도. 지역 이름(마게도냐·아가야·아시아 등)은 지형 위 **참고 라벨**로만 쓴다.
- 대한성서공회 지도 이미지의 복제·모방. 지형은 현대 해안선(Natural Earth) 위의 단순한 면이다.

## 3. 새로 그릴 것

### W1 · 지중해 전체 보기 (초대교회 필터)
- 지도가 지중해 전역을 보인다. 기록이 연결된 장소들(예: 로마, 고린도, 에베소, 빌립보, 안디옥)이 **표식으로 흩어져** 있다.
- 서로 가까운 표식은 **묶음 표식**으로 합쳐 있다. 예: 에게 해 주변 여러 곳이 `N곳` 하나로.
- 이름이 보이는 표식과 묶음 표식이 한 화면에 섞여 있다.

### W2 · 묶음 표식 (새 구성 요소)
- V1의 지역 표식(원형 + 이중 윤곽)과 **구별되는** 모양이어야 한다. V1의 이중 윤곽은 "여러 시대"를 뜻하므로 겹치면 안 된다.
- 내용: `N곳` (장소 수). 기록 수는 쓰지 않는다 — 한 장소에 노트가 여러 편일 수 있어 숫자가 두 종류가 되면 혼란스럽다. 노트 편수는 펼친 뒤에 본다.
- 터치 영역 44pt. 기본 / 선택(누르는 중) 상태.
- 누르면 **그 묶음의 구성원이 모두 보이는 범위로 이동·확대**한다(선택이 아니라 이동). 시안에는 눌렀을 때와 확대 후(W3) 화면을 둔다.

### W3 · 묶음이 풀린 확대 보기
- 묶음 표식을 누른 뒤의 화면. 에게 해 일대 장소가 각자의 이름 라벨과 함께 보인다.
- 라벨이 겹치는 곳의 처리(왼쪽/오른쪽 배치, 겹치면 숨김)를 보여 준다.

### W4 · 광역 참고 라벨
- 지형 위 맥락 라벨 세트: 바다(지중해, 에게 해, 흑해), 지방(이탈리아, 마게도냐, 아가야, 아시아, 갈라디아, 구브로, 그레데).
- 기록 표식·묶음 표식보다 엷게. 확대 정도에 따라 나타나는 규칙(V1의 maxS/minS 방식)을 같은 방식으로.

### W5 · 장소 상세 — 위치의 확신도
- 장소 상세의 "위치" 행에 정밀도를 한 줄로 쓴다: `도시 주변의 대략적인 위치` / `일대의 대략적인 위치`(지방·섬).
- 위치가 논쟁적인 장소는 **지도에 표식을 만들지 않고** 목록에만 보인다. 그 행의 모양(예: `위치가 확정되지 않아 지도에 표시하지 않아요`)을 그린다.

### W6 · 여정 (경로선 논의용 — 두 안을 모두)
사도행전의 여행 구간처럼 정차 지점을 순서대로 보는 화면. 선 처리를 정하기 전이라 **A안과 B안을 나란히** 그린다.
- **A안 — 선 없음**: 정차 지점에 번호 표식(①②③…)을 붙이고, 아래에 `여정 · 정차 N곳` 목록(번호, 장소, 관련 구절)을 둔다.
- **B안 — 점선 연결**: A안에 더해 연속한 정차 지점을 **점선 직선**으로 잇는다. 선 근처 또는 지도 하단에 항상 보이는 안내: `정차 순서를 이은 선이에요. 실제 길은 아니에요.`
- 두 안 모두 번호 표식이 선택됐을 때의 상태, 번호 표식과 일반 표식이 섞이는 경우를 보인다.

## 4. 기존 화면의 변경점

- 시대 필터 칩에 `초대교회` 추가(가로 스크롤은 V1 그대로).
- 전체 지도의 요약 문구 `N편의 기록 · N지역`에서 **지역**의 뜻: V2에서는 "묶음 전의 지역(도시) 수"로 센다.
- 지역 확대 지도(V1의 RegionMap)는 변경 없음. 묶음 표식을 거쳐 들어갈 수 있다.
- 태블릿·Dark는 위 W1–W6의 핵심 장면(W1, W3, W6)만 추가한다.

## 6. 산출물 기대

- V1 캔버스에 **새 섹션 하나**로 W1–W6를 추가하고, 구성 요소 보드(S1)에 묶음 표식·번호 표식을 더한다.
- 새로 그리는 구성 요소는 **묶음 표식**과 **번호 표식** 둘뿐이다. 나머지는 V1 요소의 재사용으로 조합한다.
- 지형·표식·라벨 레이어를 V1처럼 분리해, 실제 데이터로 교체할 수 있게 한다.
