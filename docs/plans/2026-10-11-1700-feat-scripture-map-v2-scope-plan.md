# 말씀 지도 V2 — 범위 재정의

V1 지도는 갈릴리·예루살렘·여리고(경도 34.2–36.4, 위도 31.0–33.4)에 갇혀 있다. 이 문서는
대한성서공회 성경지도 35장의 매핑(`~/Desktop/씀씀/사진/성경지도/성경지도_매핑.md`)을 범위 점검표로 삼아
**어디까지 지도에 올릴지**를 다시 정의한다. 구현 계획이 아니라 범위 정의다.

## 0. 결정 (2026-10-11)

| 항목 | 결정 |
|---|---|
| OpenBible 커버리지 | **확인 완료** — §6. P1(신약·지중해) 주요 지명 대부분이 있고 후보가 하나로 정해진 것이 많다 |
| 우선순위 | **P1(지중해·신약)을 먼저** 한다. P0(성지 완성)은 그 다음 |
| 권역 표식 | **디자인이 아직 없어 제외한다.** §2.1의 "권역" 계층과 권역 표식은 보류. P1의 광역 보기는 **거리 기반 묶음 표식(N곳)** 으로 푼다(§2.2) |
| 경로선 | **바로 구현하지 않는다.** 방식을 먼저 논의한다 — §7 |
| 연도 | **표기하지 않는다.** 근거가 명확하지 않은 연도는 지어낸 정보가 된다 |
| 시안 개정 | 필요. 요구 사항을 [브리프](../design/2026-10-11-scripture-map-v2-claude-design-brief.md)로 정리했다 |

아래 §2~§5는 먼저 쓴 정의이며, §0과 어긋나는 부분은 §0이 우선한다.

## 1. 입력 자료를 어떻게 읽었나

- 35장(구약 26 · 신약 9) 중 **12장을 직접 열어 지리 범위와 축척을 확인**했다: g01 g02 g03 g11 g19 g21 g23 · n01 n03 n05 n08 n09. 나머지 23장은 제목으로만 분류했다(아래 표에 `제목` 표시).
- 이미지는 **(재)대한성서공회 저작물**이다. 앱에 넣거나 그대로 다시 그리지 않는다. **무엇이 범위에 들어야 하는가를 가리키는 점검표**로만 쓴다. 지형은 Natural Earth, 장소 좌표는 OpenBible(RULE-MAP-007 방식)로 만든다.
- 사이트의 연도 표기는 앱에 옮기지 않는다. 서로 어긋나는 값이 있다 — 성막 BC1462가 출애굽 BC1446보다 앞선다, 바사 왕국이 BC909~886으로 적혀 있다(매핑 문서도 원문 그대로라고 밝힘). V1의 "연대는 확정하지 않는다" 원칙을 유지하고 **연도는 표기하지 않는다**(§0).

### 35장의 축척이 세 단계로 갈린다

| 단계 | 대표 지도(축척 막대) | 보이는 범위 |
|---|---|---|
| 지중해 권역 | n01 신약의 세계(800km), n08 로마로 가는 바울(500km), n05 바울 1차(150km), n09 일곱 교회(250km) | 이탈리아 – 그리스 – 소아시아 – 키프로스 – 북아프리카 해안 |
| 근동 권역 | g01 창세기의 세계(600km), g02 아브라함(600km), g23 바벨론(600km), g21 앗수르, g19 바사 | 이집트 – 시나이 – 시리아 – 메소포타미아 – 페르시아만, 바사는 인도 쪽까지 |

(권역 축척 차이: V1 전체 지도는 약 50km 단위, 지중해 권역은 800km — 16배)

## 2. 새 범위

### 2.1 계층: 권역 → 지역 → 시대별 장소

V1에는 "지역"(점 하나)만 있다. 자료의 "이집트·그리스·로마"는 그보다 한 단계 위다. 계층을 하나 더한다.

| 계층 | 의미 | 예 |
|---|---|---|
| **권역** (realm, 신규) | 시대와 무관한 넓은 지리 구획. 광역 지도의 표식 단위 | 이스라엘 · 이집트·시나이 · 시리아 · 메소포타미아 · 페르시아 · 소아시아·키프로스 · 그리스 · 이탈리아 · 북아프리카 |
| 지역 (기존) | 도시·유적 단위. 지금의 `regionKey` | 여리고, 예루살렘, 고린도, 에베소, 로마, 바벨론 |
| 시대별 장소 (기존) | 시대마다 독립된 항목 (RULE-MAP-002) | 여리고(여호수아) / 여리고(예수님 사역) |

- 장소는 `realmKey` 하나를 더 가진다. 권역은 표시 이름과 보기 범위만 가진다(범용 계층 만들지 않음, V1 판단과 같다).
- 권역 이름 자체(앗수르·바벨론 제국·마게도냐 등 영토)는 **지도의 참고 라벨**로만 쓰고 기록 표식을 만들지 않는다.

### 2.2 보기 범위 (지도 단계)

| 단계 | 번들 지형 범위 | 용도 |
|---|---|---|
| **광역 (성경 세계)** | 경도 8–62, 위도 12–47 | 시대·권역 전체 보기. 이탈리아(로마 12.5°E)부터 수산(48°E)·페르세폴리스(53°E)까지 |
| **권역** | 위 범위 안에서 권역 경계에 맞춤 | 권역 선택 시 이동·확대 |
| **성지 상세** | 경도 34.0–36.8, 위도 30.9–33.6 (V1 범위를 요단 동편·헤르몬 쪽으로 소폭 확장) | 현재 지도. 고해상도 유지 |
| 지역 확대 | 지역 중심 최소 약 30km (V1과 동일) | 도시 단위 |

- 바사 왕국(g19)이 가리키는 인도 방향(62°E 밖)은 **자른다**. 수산·페르세폴리스까지가 범위다.
- 광역 전체 보기에서 성지 전체는 **약 12px**다(폭 350px 기준). 그래서 광역에서는 권역 표식(예: `이스라엘 7편`)을 보이고, 확대하면 지역 표식으로 풀린다 — V1에서 없앤 거리 기반 묶음 대신 **권역/지역 계층으로 푼다**.
- 전체 보기 범위는 고정이 아니라 **현재 시대 필터에 걸린 지역들을 감싸는 범위**(최소 성지 상세 크기)로 자동 맞춘다. 예: 예수의 생애만 → 성지, 초대교회 → 지중해, 전체 → 광역. 권역 선택은 그 권역 범위로 이동·확대한다.

### 2.5 위치를 못 박기 어려운 곳

에덴·바벨탑·시내산·일부 도피성은 위치가 논쟁적이다. V1 규칙(검증된 근거가 있는 항목만, `source`에 CC BY 4.0 링크)상 **좌표를 만들어 넣지 않는다.** 필요하면 "위치 논쟁/미상" 상태를 새로 정의해 목록에만 보이고 지도 표식은 만들지 않는다.

## 3. 단계 제안 (§0에 따라 P1 먼저)

**진행 순서: P1 → P0 → P2 → P3.** 표의 번호는 이름표일 뿐 순서가 아니다.

| 단계 | 범위 | 성경지도 | 이유 |
|---|---|---|---|
| **P0 성지 완성** | 성지 상세 범위 소폭 확장, 시대 3 → 6~7개, 사건 데이터 확충 | g05–g12 g14–g16 g20 g22 g27 n02 (15장) | 지금 구조 그대로. 지형 확장이 거의 없다 |
| **P1 지중해 (신약)** | 광역 지형 + 권역 계층 + 소아시아·그리스·이탈리아 장소 | n01 n04~n09 (7장) | **서신서·사도행전의 수신지·방문지가 전부 도시 점**이라 경로선 없이도 가치가 크다 (로마서·고린도서·에베소서 등). 설교 본문에 가장 자주 닿는 구간으로 보인다 |
| **P2 근동 (구약)** | 이집트·시나이·시리아·메소포타미아·페르시아 | g01 g02 g03 g17 g19 g21 g23 g24 g26 (9장) | 위치 불확실 항목이 많고 경로·영토 비중이 높아 마지막 |
| **P3 별도 결정** | 경로선, 영토 면 | 위 형태 표의 제외분 | 각각 디자인과 데이터 비용이 크다 |
| (범위 밖) | 도면 | g04 g13 g18 n03 | 지도가 아님 |

(합계: 15 + 7 + 9 + 4 = 35)

## 4. 코드·정본에 미치는 영향

**측정한 것**
- 광역 범위(경도 8–62, 위도 12–47) 지형 JSON: 허용오차 약 2km에 **88KB**, 약 5km에 **40KB**. 지중해만(경도 8–45, 위도 28–47)은 2km에 60KB. 번들 크기는 문제가 아니다.
- ⚠️ **현재 지형 스크립트는 바깥 고리만 쓴다.** Natural Earth 육지에서 **카스피 해는 구멍(hole)** 이라(중심 50.7°E 41.9°N) 그대로 쓰면 육지로 그려진다. 광역에는 구멍 처리가 필요하다.

**바뀌어야 하는 것** (추정, 구현 전 확정 필요)
- `OVERVIEW_BOUNDS` 고정 → 필터 결과에 맞춘 자동 범위, 권역 선택 시 범위로 이동. 현재 확대 한계(`maxK` 10)로는 광역에서 성지까지 못 내려온다(축척 약 32배 차이) — 배율 한계가 아니라 **범위 맞춤 이동**으로 풀어야 한다.
- 맥락 라벨 32개가 전부 성지 지명이고 노출 임계값도 성지 축척 기준이다 → 권역용(이집트·그리스·로마·바벨론 등)과 성지용 두 벌.
- 데이터: `Place.realmKey`, `Period` 추가, 사건·장소 JSON 확충(`map-data.test.ts`의 출처·정밀도 검증은 그대로 적용).
- 디자인: **시안은 성지 한 단계만 그렸다.** 광역 권역 표식, 광역→권역→지역 전환, 광역 라벨을 담은 시안 개정이 먼저 필요하다.
- 정본(wiki): `RULE-MAP-001`(수록 5건 → 확장·시대 목록), `-002`(권역 계층), `-003`("N지역"의 정의 — 권역인지 지역인지), `-006`(번들 크기), `-007`(새 데이터의 출처). V2 구현과 같은 변경에서 갱신한다.

## 5. 남은 결정

1. **경로선의 방식** — §7에서 논의.
2. **묶음 표식(N곳)의 디자인** — 권역 표식과 다른, 거리 기반 묶음이다. 시안 개정에 포함했다(브리프). 이것도 보류할지 확인이 필요하다.
3. **P1 시드 범위** — §6.3의 후보 중 어디까지 넣을지(사도행전 중심 vs 일곱 교회 포함).

## 6. OpenBible 확인 결과 (2026-10-11)

`openbibleinfo/Bible-Geocoding-Data`의 `data/ancient.jsonl`을 내려받아 조사했다(CC BY 4.0, 장소 1,342개). 조사 스크립트와 원본은 임시 폴더에만 있고 저장소에는 넣지 않았다.

### 6.1 데이터가 가진 것
- 장소마다 **성경 구절 목록**(`verses`, OSIS 참조), **식별 후보 목록**(후보마다 좌표·종류·신뢰 점수), 위치 유형(`point` 점 / `polygon`의 대표점)을 가진다.
- 좌표가 없는 장소는 1,342개 중 7개뿐이다. 1,329개가 광역 범위(경도 8–62, 위도 12–47) 안에 있고, 그중 성지 상세 범위(경도 34.0–36.8, 위도 30.9–33.6)는 941개, **성지 밖은 388개**다.
- **후보가 하나뿐**이고 점수 500이면 학계에 큰 이견이 없다는 뜻이다(저장소 설명). 후보가 여럿이거나 평균 점수가 낮으면 위치가 논쟁적이다.

## 7. 경로선 논의 (구현 전)

대한성서공회 지도 35장 중 8장이 이동 경로다(아브라함, 출애굽, 엘리야, 엘리사, 바울 4회). 선을 그리는 방법을 먼저 정해야 한다. **지도 이미지는 저작물이라 베끼지 않으므로, 선은 우리 데이터로 만들어야 한다.**

### 7.1 기준: 선이 사실처럼 보이면 안 된다
- 성경 본문이 말해 주는 것은 **정차 지점과 순서**이지 실제 경로(도로·항로)가 아니다.
- 따라서 선이 그려져 있으면 사용자는 "이 길로 갔다"고 읽는다. 근거 없는 곡선은 지어낸 정보다.

### 7.2 선택지

| 안 | 내용 | 장점 | 위험 |
|---|---|---|---|
| **A. 선 없음** | 정차 지점을 번호 표식(①②③…)과 "여정" 목록으로만 보인다 | 지어낸 정보가 없다. 구현 작다 | 지도에서 흐름이 한눈에 안 읽힌다 |
| **B. 직선 연결** | 연속한 정차 지점을 점선 직선으로 잇고 "정차 순서를 이은 선이며 실제 경로가 아니에요"를 항상 곁들인다 | 흐름이 보인다. 새 데이터 없음 | 바다·산을 가로질러 틀려 보일 수 있다 |
| **C. 경유점을 손으로 넣은 곡선** | 항로·도로를 따라 중간 좌표를 넣는다 | 보기 좋다 | 경유점마다 근거가 필요하다. **근거 없이 넣으면 지어낸 정보** |
| **D. 고대 도로·항로 데이터셋** | 공개 데이터에서 가져온다 | 가장 정확 | 별도 라이선스·데이터 조사와 번들 크기가 필요. 지금은 범위 밖 |

### 7.3 정차 순서는 지어내지 않아도 된다
OpenBible의 장소마다 **언급되는 구절 목록**이 있다. 한 여정의 구절 범위(예: 사도행전 13:1–14:28 = 1차 선교 여행)를 정하면, 그 안에서 장소를 **구절 순서대로 정렬**해 정차 순서를 얻을 수 있다. 순서는 본문에서 나오므로 검증 가능하다. 범위와 순서가 맞는지는 사람이 한 번 확인한다.

### 7.4 권장
1. **1단계: 안 A** — 정차 번호 + 여정 목록. 순서는 구절 순서에서 얻고 근거(구절 범위)를 `basis`에 남긴다.
2. **2단계: 안 B를 선택 사항으로** — 디자인이 정해진 뒤에, 점선과 안내 문구를 곁들여 추가한다. 안 C·D는 근거가 확보될 때만.
3. 시안 개정에서 **A와 B 두 가지를 모두 그려** 비교한 뒤 정한다(브리프에 포함).
